# Code de conduite

## Notre engagement

Nous nous engageons à faire de la participation à ce projet une expérience
sans harcèlement, accessible à tous, quel que soit l'âge, le handicap,
l'identité et l'expression de genre, l'expérience, la nationalité,
l'apparence physique, l'origine, la religion ou l'orientation sexuelle.

## Nos standards

Comportements qui contribuent à un environnement positif :

- faire preuve d'empathie et de bienveillance ;
- respecter les opinions et expériences différentes ;
- accepter la critique constructive avec grâce ;
- se concentrer sur ce qui est le mieux pour la communauté.

Comportements inacceptables :

- contenu sexualisé, avances ou remarques à caractère sexuel ;
- attaques personnelles, trollage, commentaires insultants ou désobligeants ;
- harcèlement public ou privé ;
- publication d'informations privées d'autrui sans permission explicite ;
- toute conduite jugée inappropriée dans un cadre professionnel.

## Application

Les instances de comportement abusif peuvent être signalées aux
responsables du projet via les [issues GitHub](https://github.com/mickael-cala/MCPserver-HTTPSuite/issues)
ou par les moyens de contact listés dans le profil du détenteur du dépôt.
Toutes les plaintes seront examinées et feront l'objet d'une réponse
appropriée.

Ce code de conduite est adapté du [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
